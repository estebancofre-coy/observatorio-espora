INICIO DEL LEVANTAMIENTO

Identificación del establecimiento

Paso inicial

Identifique el local y la fecha de observación. Estos datos se comparten con todas las pautas y se guardan en este dispositivo para retomar el trabajo. La persona responsable se registra dentro de cada pauta.

Ver mapa de unidades vecinales (Google Earth)

La UV se sugiere según las coordenadas del local. Revísela y corríjala si el punto está cerca de un límite.

Filtrar esta lista por UV — no es otro dato de la visita

La lista muestra código, nombre y dirección para identificar el local sin memorizar el número.

Primero filtre o revise la lista de locales de muestra. Active esta opción solo si el local no está registrado.

La dirección se vinculará a la unidad vecinal indicada por el GPS o seleccionada abajo.

Use «Generar otro código» solo si el sistema avisa que el código ya está ocupado.

GPS del dispositivo

Ingrese las coordenadas GPS para sugerir la unidad vecinal. La dirección del local quedará vinculada a la UV indicada aquí.

Visita activa

Pauta opcional

Pautas de observación, en este orden

La clasificación se aplica solo a los locales que la requieren. En pescaderías y carnicerías pueden aplicarse únicamente origen y precios. Cada pauta registra a su propia persona responsable.

Descargar respaldo offline

El respaldo permite recuperar el trabajo de este dispositivo; no sustituye guardar los instrumentos en Sheets.

Finalizar visita

Guarde los instrumentos en Sheets antes de cerrar. El cierre elimina el borrador de este dispositivo.

Pauta de disponibilidad y variedad

Transcripción de la pauta original: se excluye únicamente la sección de publicidad.

Pauta de registro de precios

Registre los alimentos centinela disponibles. Si hay varias opciones de un mismo alimento, anote solo la de precio más bajo y la de precio más alto. El botón de guardado abre la pantalla de revisión.

Revisión de alimentos y precios

Revise los alimentos registrados. Cada uno debe tener al menos el precio más bajo; si existe más de una opción, agregue también el más alto.

Agregar alimento y precios

Registre el precio más bajo y, si hay más de una opción (marca, formato o calidad), también el más alto. Los productos emblemáticos regionales se registran solo si fueron identificados en la pauta de origen.

Pauta de clasificación de establecimientos alimentarios

Pauta opcional. Para clasificar automáticamente como «minimarket» se requiere autoservicio o atención mixta y cumplir al menos dos de los tres criterios de surtido. Una corrección manual exige justificación. Abrir la guía de clasificación
